# QA 收集表体检清单（拿到伙伴填表时可主动核对）

伙伴回填 QA 表时容易填错或误解字段。拿到表后可主动过一遍下面的清单，帮用户/伙伴避免串场和歧义。这些发现来自对《伙伴QA收集表模版》的实审，可复用。

## 一、易填错（会直接导致内容错误，高优先级）

1. **客户案例区「解决方案整体价值」易被复制粘贴串场**
   - 症状：这一栏填的却是**另一个方案**的价值（如 PB Tech 云直播案例里，误填成了信永中和财务方案的"23国108办公室/国资委标准"）。
   - 处理：解析时若发现价值描述与"客户采购的解决方案/涉及产品"对不上，提示用户核对是否粘错。

2. **示例列（简略示例）不是待填内容**
   - 客户案例区常见占位如"（示例见上7）""（示例见上9）"，是指向联合方案区对应字段的参考，**不是真实内容**。解析真实项目以"待填写"列为准。

3. **示例被填成占位符会被照抄**
   - 如"客户目标出海国家/地区"示例写"--"、"伙伴在案例中提供的服务"示例留空——伙伴可能照着填空。建议给真实示例（如"东南亚、中东"）。

## 二、易混淆（概念不清导致填偏，中优先级）

4. **「方案整体价值」 vs 「方案效益」**
   - 整体价值 = 能力叙述（定性）；效益 = 可量化数据（定量）。
   - 建议：字段名可改为「方案效益（量化数据）」，加提示"请尽量用百分比/倍数/时间对比等硬数据"。

5. **「解决方案整体价值」 vs 「客户收益」（客户案例区）**
   - 整体价值 = 方案端能力（供给侧，"方案能……"）；客户收益 = 该客户实际拿到的结果（结果侧，"客户得到了……"，带量化数据）。
   - 建议：字段名可改为「解决方案整体价值（方案能力）」和「客户收益（该客户实际成效）」，避免两栏填成一样。

6. **联合方案区「方案整体价值」 vs 客户案例区「解决方案整体价值」措辞太像**
   - 建议加区分提示：一个讲方案通用价值，一个讲落到具体客户的方案价值。

## 三、体验优化（低优先级）

7. **「方案差异化价值」建议加填写提示**
   - 主打"你有我没有"，提示语可写："请对标竞品（如其他云厂商同类方案），点出**只有腾讯云×贵司能提供、竞品给不了**的价值点。"

## 处理原则

- 默认**只在对话里给建议**，不擅自改动伙伴的 xlsx 文件（除非用户明确说"帮我改表格"）。
- 体检是辅助，不阻塞主线；即使表有小瑕疵，也先按现有内容推进故事线，同时把发现列给用户。
